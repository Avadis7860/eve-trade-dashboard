# Index canonique du code

**État :** Phase G04 (Déduplication Corporation & Sondes de Sauvegarde : clé composite immuable `(corporation_id, division, journal_id)`, déduplication multi-directeurs garantie à 100% sur PostgreSQL, sauvegarde et restauration atomique SHA-256 avec exercice Disaster Recovery à delta ISK nul, sondes de vivacité et de préparation `/health/live` et `/health/ready` avec gestion 503 en cas de panne DB) terminée et validée.

## Runtime & Environnement
- **Runtime :** Node.js 22, TypeScript strict.
- **Port d'écoute :** 3000 (0.0.0.0).
- **Points d'entrée :**
  - Serveur : `server.ts`
  - Client SPA : `src/main.tsx` (via `index.html`)
- **Scripts npm :**
  - `npm run dev` : Démarrage du serveur full-stack avec middleware Vite (`tsx server.ts`).
  - `npm run build` : Compilation TypeScript et build statique client Vite (`tsc && vite build`).
  - `npm run lint` : Vérification ESLint (`eslint src/ server.ts`).
  - `npm run typecheck` : Vérification des types sans émission (`tsc --noEmit`).
  - `npm test` : Suite de tests unitaires et intégration Vitest (`vitest run`).
  - `npm run test:integration` : Exécution de la suite d'intégration PostgreSQL sur moteur SQL réel (`vitest run src/server/storage/postgres.real.test.ts`).
  - `npm run test:e2e` : Exécution de la suite de tests End-to-End Playwright dans un navigateur Chromium réel (`playwright test`).
  - `npm run bench` : Exécution du banc de charge, profiling mémoire et latence HTTP sous volumétrie (`tsx scripts/baseline-bench.ts`).
  - `npm run bench:baseline` : Alias pour le benchmark de performance de référence (`tsx scripts/baseline-bench.ts`).
  - `npm run db:recalculate-financials` : Commande de maintenance et de reconstitution financière historique avec rapport d'écart contradictoire (`tsx scripts/recalculate-financials.ts`).
  - `npm start` : Démarrage en production (`NODE_ENV=production tsx server.ts`).

## Variables d'environnement
- **Variables applicatives :**
  - `PORT` : Port d'écoute HTTP local du serveur (par défaut: 3000).
  - `SESSION_ENCRYPTION_KEY` : Clé de chiffrement maître AES-256 (32 octets / 64 hex), obligatoire sans fallback en mode production.
  - `DATABASE_URL` : URL de connexion PostgreSQL pour persistance relationnelle externe (optionnel, bascule automatiquement vers adaptateur fichier durable si absent).
  - `DATABASE_STORAGE_PATH` : Chemin du fichier de persistance atomique locale (par défaut: `./.data/eve_trade_store.json`).
  - `LOG_FORMAT` : Format de sortie des journaux serveur (`json` pour production structurée ou standard).
- **Variables OAuth EVE Online :**
  - `EVE_CLIENT_ID` : Identifiant client OAuth de votre application EVE Online Developer.
  - `EVE_CLIENT_SECRET` : Clé secrète de votre application EVE Online Developer.
  - `EVE_CALLBACK_URL` : URL de rappel de redirection configurée sur le portail développeur EVE.
