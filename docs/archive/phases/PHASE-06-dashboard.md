# PHASE-06 — Dashboard intégré

**Type :** développement · **Dépendances :** 03–05

Objectif : assembler un parcours quotidien de consultation des ventes, revue des ordres et préparation des achats.

Inclus : vue d'ensemble ; vues Ventes, Ordres, Achats à préparer ; filtres cohérents ; détails avec provenance, frais et incertitudes ; préférences ; états loading/fresh/stale/partial/empty/unavailable/error/unknown ; export CSV si son contrat est testé.

Exclus : nouvelles sources, actions EVE, scanner d'opportunités, recommandations Gemini.

Sortie : tests composants de tous les états ; parcours consultation-filtrage-revue-liste ; aucune écriture ESI ; KPI cohérents avec filtres ; export sécurisé s'il est livré ; code index et UX à jour.
