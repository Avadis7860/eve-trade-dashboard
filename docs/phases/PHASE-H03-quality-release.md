# PHASE-H03 — Hardening UX, performance et release

**Type :** hardening · **Dépendances :** H01–H02

Objectif : stabiliser l'usage quotidien et rendre la publication reproductible.

Contrôles : accessibilité clavier/focus/contraste/tables ; performances de listes et agrégats ; concurrence de sync ; compatibilité navigateur ; redémarrages et déploiement ; sauvegardes, migrations, rollback ; précision des indicateurs de fraîcheur.

Sortie : E2E stables avec ESI/SSO simulés ; audit accessibilité ; budget et mesures de performance ; guide d'exploitation, restauration et retour arrière ; CI, index et documentation vérifiés ; risques résiduels consignés.
